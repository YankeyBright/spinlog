# Support

## Usage Questions

Search existing GitHub issues before opening a focused question. Include the `spinlog` version, Node.js version, operating system, terminal, relevant environment variables, and a minimal reproduction.

## Bugs

Use the bug report form for reproducible defects. Unsupported Node versions, CommonJS, browser runtimes, custom streams, and deferred post-MVP APIs are outside the v1 support contract.

## Security

Follow [SECURITY.md](SECURITY.md) for private vulnerability reporting. Do not include sensitive security details in public support requests.
